ngx-stripe follows Angular majors and Stripe.js named trains. Version = {angularMajor}.{stripeJsMajor}.{patch}. Use Pick your lane and the installation table (generated from lanes.json).

  • active — current Angular majors with published Stripe trains. Bugs and Stripe sync land here first.
  • maintenance — previous Angular majors. Fixes and train sync as practical; prefer upgrading when you can.
  • lts / best-effort / legacy — older lines via dist-tags when published. No guarantee of every Stripe train.

Appearance, payment methods, and Element options are almost always Stripe.js concerns — start with Stripe docs. File an ngx-stripe issue for Angular DI, Observables, loader CDN, or Element host lifecycle.

  • GitHub issues: richnologies/ngx-stripe
  • Include Angular major, ngx-stripe version, and @stripe/stripe-js major
  • Security: see SECURITY.md in the repo (private email, not a public issue)
