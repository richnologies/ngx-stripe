Removed on Stripe.js v10 (endive)

Stripe dropped the Payment Request Button Element. ngx-stripe *.10 no longer ships ngx-stripe-payment-request-button.

Use Express Checkout Element (ngx-stripe-express-checkout) or Payment Element for wallets. The stripe.paymentRequest() method is still typed if you need a custom button.

Stay on dahlia if you still need the old Element: npm install ngx-stripe@v22-dahlia @stripe/stripe-js@^9. See Migration.
