On basil and newer, do not pass a legacy apiVersion into Stripe() / provideNgxStripe options — that constructor option is unsupported on those trains and will throw. Align @stripe/stripe-js major with the middle digit of ngx-stripe instead.

Policy: Stripe.js versioning.

  • active — current Angular majors with published Stripe trains (see the release matrix).
  • maintenance — previous Angular majors; fixes and Stripe-train sync as practical.
  • lts / best-effort / legacy — older lines; install from the matching dist-tag when published.
